About the Project

Students Grading
System

A complete Machine Learning pipeline trained on real student data to predict academic outcomes with confidence.

This project is a complete Machine Learning pipeline built to predict student academic outcomes. The system trains five classification algorithms on the StudentsPerformance dataset containing 1,000 student records with demographic, social, and academic variables.

The best-performing model — a Logistic Regression Classifier — achieved 96.0% accuracy on the held-out test set. The system flags whether students will pass (scoring ≥50 in Math, Reading, and Writing) or fail, helping educators intervene early.

The pipeline is built using scikit-learn's Pipeline and ColumnTransformer APIs, ensuring preprocessing (One-Hot Encoding + Standard Scaling) is seamlessly integrated into the model with no data leakage. Hyperparameter optimization is performed via GridSearchCV with 5-fold cross-validation.

How the ML Pipeline Works

A step-by-step overview of the data science process from raw data to live prediction.

01

Data Ingestion & Feature Engineering

Raw student records are ingested from CSV. A binary target variable passed is derived: students passing Math, Reading, and Writing with ≥50 are labeled Pass (1), otherwise Fail (0). A stratified 80/20 train-test split maintains class proportions.

02

Preprocessing with ColumnTransformer

A scikit-learn ColumnTransformer applies OneHotEncoder(drop='first') to categorical features and StandardScaler() to numerical features. Both are embedded inside the Pipeline to prevent data leakage.

03

GridSearchCV Hyperparameter Tuning

Five classifiers (Logistic Regression, Decision Tree, Random Forest, KNN, SVC) are each wrapped in a Pipeline and tuned with GridSearchCV using 5-fold cross-validation. The optimal hyperparameters are automatically selected.

04

Evaluation & Model Selection

All tuned pipelines are evaluated on the held-out test set. Accuracy, Precision, Recall, F1-Score, and a full Classification Report are generated. The winner (Logistic Regression at 96.0%) is saved as a unified best_pipeline.pkl.

05

Flask API & Live Prediction Serving

A Flask REST server loads the saved pipeline and exposes a POST /api/predict endpoint. Raw JSON inputs are fed directly into the pipeline, returning the prediction label and confidence probability. The website calls this endpoint in real time.
